# Every control, before and after — the round of 13 November

Each of the screens photographed for this round was opened in the build from before it (commit `db90bcf`) and in the build after it, in Simplified Chinese, and every control on it listed by what it is, what it is called and whether it can be used — buttons, tabs, fields, menu rows, switches, sliders, options. This is those two lists compared: the answer to “is everything that was there still there, under the same name?”

- **2715** controls before, **2715** after, over 19 screens and states.
- **2715** are the same control with the same name in the same state.
- **0** are new on these screens, **0** were not found after.

The one control this round adds is not on these screens: **About Lumen › 日志 › 显示文件** (“Log › Show the file”), which exists only in the desktop app. The list was taken from the editor running in a browser tab, as the screenshots were.
